## 실제 복구 확인

1. 저장소에 재사용할 order_data 자료가 없는 것을 확인했다.
2. StockAnalysis 표는 6개월 표시와 달리 이번 읽기에서 50행, 1 of 3으로 표시됐다. 읽기 도구에 실제 다음 페이지 링크가 제공되지 않아 임의의 페이지 매개변수를 만들지 않았다.
3. FinanceDataReader의 실제 Naver 코드에서 기간 자료 경로를 확인했지만, 해당 원자료 조회는 현재 웹 도구에서 접근 실패했다.
4. 별도로 공개 코드에 제공된 Naver siseJson 기간 조회 형식을 확인하고 LS ELECTRIC·삼성전기에 적용했으나 웹 도구에서 접근 실패했다.
5. Yahoo 과거 일봉, Stooq 및 다른 공개 조회 경로도 확인했지만 이번 환경에서 필요한 추가 연속 구간을 가져오지 못했다. Nasdaq의 TXN 역사표는 다운로드 표시가 있어도 실제 가격표가 비어 있었다.
6. TXN의 Investing 역사표는 더 짧은 최근 구간만 제공했다. 자료원을 섞어 확보 일수를 늘리지 않았다.
7. 계산 환경의 직접 다운로드는 DNS/네트워크 오류로 실행되지 않았다. 웹에서 자료를 읽은 것과 계산 환경에서 직접 받은 것을 구분했다.
8. 다른 한국·미국 종목의 Naver 일봉 조회도 실패했다. 응답 없는 종목을 분석 완료 종목 수로 합산하지 않았다.
